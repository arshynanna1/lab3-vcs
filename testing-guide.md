# Пам'ятка тестувальника

1. Перед початком тестування перевірте, що всі залежності встановлені.
2. Запускайте тести командою pytest для Python або відповідною для вашої мови.
3. Кожен тест має перевіряти одну конкретну поведінку.
4. Якщо тест падає — спочатку перевірте, чи правильно вказані вхідні дані.
5. Після виправлення коду запускайте всі тести, а не тільки той, що падав.
